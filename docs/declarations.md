# Declarations (Solution Document §16)

## Data

All data is synthetic, generated by `services/simulator` from a fixed seed, or comes from public sources listed below. No real personal data, real VINs or vehicle-owner data is used. Synthetic VINs use the WMIs in `data/reference/wmi_synthetic.csv`.
